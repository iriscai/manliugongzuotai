2026-11-04，依据用户追加的四份提示词与先前公众号创作 Agent，新增四套独立的军事提炼规则和写文提示词。当前军事各版使用共同的直接成文与轻观点规则，保留状态和默认 C 选择；其他赛道、已安装 SKILL、已有结果与推送回执不改写。

用户后续确认增加短篇字数，当前篇幅以本表为准。可见字符按去除空白计算，HTML 标签和 CSS 不计入。

## 学到并落实的共同方法

先完整读本条素材与种子，建立事实底稿，核对专名、单位、时间、公开动作、机构说法和未知；选题、标题和判断由具体证据推动。事实与原文一致，句式、段落与解释顺序独立重构。

提炼和写文分别调用一次模型；写文的实际初稿和局部自改在同一次响应中完成，不另发多轮评审。保存事实与种子、实际初稿、自改HTML、修改摘要和材料缺口。最终正文不显示候选结构、思考过程或自检报幕。

Agent 中的身份、真实经历、个人语料和人工改稿对照仍未填写，所以学习其事实、表达和修订方法，不假称已复刻个人履历。自改不添加采访、朋友爆料、军旅经历、心情和检测结果。

## 各版本的差别

D 的提炼围绕成本承担、产能、保障和经济联系，短文只抓一个真实矛盾，不堆六个热词。原参考同时要求句号与问号，本版按具体反问收尾；一段和逗号串句要求沿用用户此前明确修正的自然分段、正常标点。

E 先识别原文入口、主抓手和事实顺序，再在内部比较多种可行结构，避免“现象—背景—工业体系升华”的惯性。参考中的5–10个事实为材料丰富时的识别方法，不编事实凑数量。只清理成品中的脚注、检索代码和网页显示痕迹，必要的事实说法归属保留；输入证据完整留档。

F 保留原题主体、动作和真实爆点，采用自然轻改，避免机械近义替换。长文需要至少五件真实具体材料，章节服从信息转向。消息来源按输入的真实机构、公告或采访交代，不编权威报告，不把用户参考里的平台建议声称为已核验官方规则。不声称“查重低于15%”已经实测。

G 保留有证据的主要判断，换开头、事实排序和论证路线，避免逐段复写；可以用准确判断收尾，不强迫反问。涉及中国能力的积极判断落实在具体公开事实，话题无关或证据不足时不强插赞词。来源仅在内部记录中保存，不自动附在成品文尾，也不冒称已核查一手报告。

## 版式与材料边界

所有版本沿用用户已确认的公众号兼容 HTML、内联CSS、正文12px加粗、自然标点和分段。F的h3章节标题安全保留，编辑和计数按当前版本执行。正文、文尾来源仍保存为可检索纯文字，独立HTML字段与导出提供排版。

本次没有增加联网研究服务，也没有执行真实军事检索。素材中的补充搜索要求只在确有实际检索结果时成立，不能用模型记忆充当查证。资料不足先缩小议题；仍无法支撑对应篇幅时记录具体缺口，不重复解释凑字，也不伪造完稿。

## 入口和启停

在“规则配置 → 军事”查看 A–G，提炼和写文分别选择 D/E/F/G，保存军事执行方案。新四套规则按启用状态提供选择，默认选择仍保留 C；可单独停用任一版本。已有批次使用原快照，不因新增版本被自动改写。
