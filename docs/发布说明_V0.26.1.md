# 漫流工作台 V0.26.1

军事成稿以前经常写成“素材转述、原文审查”，且300字限制不够讲清事件。本版增加独立军事C–G方案，并将提炼和写文统一为事件报道、自然口述和少量个人观察。

- C/D/E正文400–600字；F合计1200–1500字；G正文700–800字。
- 态度融入具体观察，短篇通常一句、最多两句，不单列支持宣誓段。
- 明确事件时间与发布日期，内部保存出处、事实核对与缺口；G不自动附输入来源。
- 旧军事规则保存历史，默认C及启停状态保留；历史稿、其他赛道与推送回执保留。
- 保留旧稿的字数显示和编辑规则，重新生成后使用新版规格。

验证涵盖各版提炼/写文路由、字数与HTML、安全导出、编辑历史、迁移幂等、非军事规则保护及冻结程序启动。此前做过两次单条真实调用；最后的轻观点样稿为编辑修订示例，不宣称已做批量质量评估。

Windows便携包解压后启动“漫画文章工作台.exe”。下载包不含业务数据库、账号配置、执行日志或浏览器会话；首次运行在界面配置执行方式、正文抓取工具和推送目标。
