# 军事个人IP直接报道 V0.26.1

直接面向读者讲事件：有依据的事件时间、主体、动作、经过、具体变化，再顺着事件作分析。成品不出现“素材转述”“原文称”等对输入文本说话的痕迹，出处、核对和缺口保留内部。

## 当前篇幅与版式

- C、D、E：正文400–600个非空白可见字符，标题另计。
- F：标题与正文合计1200–1500个可见字符，标题最多30字符。
- G：正文700–800个可见字符，标题另计；不自动附输入来源目录。

HTML正文12px加粗，内联CSS，正常标点和自然分段。C/D不强制反问结尾。历史短稿按其生成时的旧版篇幅显示、编辑，重新生成才采用新规格。

## 自然口述

句子讲清谁做了什么、怎样接下去，用具体主语和动作解释。清除“保障余地、行动成色、运行维护负担”等没有展开的报告腔，不靠堆方言、口头禅、英文和病句假装自然。初稿和局部自改在同一次响应完成，自改增加口述检查。

## 正向立场与轻观点

采用中国作者视角，立场积极、建设性，认同融在对具体做法、进展和后续发展的观察中。主要篇幅写事件和必要解释，不单列“我支持、我赞成”等宣誓段。

400–600字短篇的显性个人语气通常一句，最多两句，约20–40字。可按事件选择“我好奇”“是否”“令人期待”等句法，不能每篇集齐三个口头禅，不把长篇支持机械替换成长篇期待。保持整篇有自己的分析，精简的是反复表态。

实际机构、公告和发言者按事实交代，单方主张不升级成确定事实，不虚构经历、成绩、战果、官方意图或未公布的计划。“是否”用于待观察的内容，不把已确认事实重新变成悬念。

## 提炼、留档与升级

提炼围绕事件本身和一个具体观察点，核对稿件发布日期与事件日期；模型输入带北京时间日期。不要把题目写成“材料能证明什么”，也不让缺口清单成为整篇文章。

军事14份提炼/写文规则升级并保留旧规则到prompt_history，启停状态和默认C保持。其他赛道、已安装SKILL、既有稿件和推送回执不改写。原始输入、证据、实际初稿、自改HTML与修改摘要继续内部留档。
