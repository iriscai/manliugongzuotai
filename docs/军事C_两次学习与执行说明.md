## 执行与保存

在“规则配置 → 军事”分别选择提炼 C、写文 C，保存军事执行方案；该配置只作用军事赛道。A/B 保留，也可选择跟随全局 A/B。任务启动后沿用规则快照，修改不追溯改变在途任务。

流程为原始正文 → 军事 C 事实元素和独立选题 → 正文、元素、分类一起送入军事 C 写文 → 一次响应内初稿与局部自改 → 字数、结构、HTML 安全校验 → 结果库。正常 1→1 流程为一次提炼调用、一次写文调用，不为初稿、自改另发评审调用；原有网络错误重试机制保留。

结果库保存可检索的纯文字标题、正文以及独立 HTML 字段；阅读面板显示 12px 加粗正文，提供“导出公众号HTML”。编辑器修改纯文字，保存后重建安全的 HTML。只保留允许的文字与样式，不直接渲染模型提供的脚本或事件。

每篇同时保存在当前数据目录下 `military-drafts/<批次>/<素材ID>-<种子ID>/`：

- `素材与事实.md`：原始输入、提炼依据与来源边界。
- `0-AI初稿.md`：模型本次实际返回的初稿，后续手动编辑成品不覆盖它。
- `1-自改稿.html`：本次自改正文。
- `改动与缺口.json`：简短改动摘要、材料缺口和成稿状态。
- `版本.json`：提示词版本摘要、用户尚未确认的标记。

军事仍按既有非搞笑规则默认 60 分，不新增冒充质量评估的自评分。
